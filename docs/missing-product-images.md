## How to Wire Images

Each product file (e.g. `src/data/products/catalog/batteries/discover-helios-ess-52-48-16000.ts`)
needs an `imageUrl` line. Add it after the `name` field:

```ts
const product: Product = {
  id: "discover-helios-ess-52-48-16000",
  manufacturer: "Discover Battery",
  name: "HELIOS ESS 52-48-16000",
  imageUrl: "/product-images/discover/discover_helios.svg",  // ← add this
  productType: "battery",
  // ...
};
```

The batch script at `scripts/add-product-images.mjs` can automate this when ready.
