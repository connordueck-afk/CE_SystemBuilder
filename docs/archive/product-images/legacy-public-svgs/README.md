# Legacy public SVG assets

These product SVGs were previously stored under `public/product-images/` but
were not referenced by the active catalog, generic fallback map, or dynamic
product-image resolver when archived.

They are retained here for future product work while remaining outside Vite's
`public` directory, so they are not copied into production builds. Paths below
this directory mirror their former paths below `public/product-images/`.
